Always follow SDD workflow: 1. Author or update specifications (/kn-spec). 2. Plan and decompose tasks linked to spec (/kn-flow or /kn-plan). 3. Implement incrementally following TDD/Clean Code. 4. Verify against spec acceptance criteria and module boundaries (/kn-verify). 5. Commit structured changes with conventional commit format (/kn-commit).
